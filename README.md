This repository publishes software I make to Homebrew and the AUR:

- [riptags]
- [csskit]

## Homebrew

```sh
brew install keithamus/tap/riptags
brew install keithamus/tap/csskit
```

## AUR

```sh
yay -S riptags-bin
yay -S csskit-bin
```

[riptags]: https://github.com/keithamus/riptags
[csskit]: https://csskit.rs/
