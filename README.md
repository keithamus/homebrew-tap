This repository publishes software I make to Homebrew and the AUR:

- [riptags]
- [csskit]
- [git-worktree-share]

## Homebrew

```sh
brew install keithamus/tap/riptags
brew install keithamus/tap/csskit
brew install keithamus/tap/git-worktree-share
```

## AUR

```sh
yay -S riptags-bin
yay -S csskit-bin
yay -S git-worktree-share
```

[riptags]: https://github.com/keithamus/riptags
[csskit]: https://csskit.rs/
[git-worktree-share]: https://github.com/keithamus/git-worktree-share
